# Roadmap G+G после Phase E

## P1

- поиск по transcript;
- переход к последнему непрочитанному сообщению и кнопка прокрутки вниз;
- сохранение scroll position отдельно для каждого проекта;
- индикатор provider/run у composer и статусы «генерирует / ждёт выбора / скачивает / остановлено»;
- единый центр пользовательских ошибок вместо raw-сообщений;
- retry конкретного failed step без повторной отправки пользовательского сообщения;
- полный аудит focus order, ARIA и keyboard navigation;
- настройка плотности интерфейса;
- финальный Phase D Live UAT в стабильной сети: максимум один контролируемый запрос на provider.

## P2

- закреплённые проекты, настоящий архив отдельно от корзины и теги;
- экспорт/импорт одного проекта;
- сравнение ответов моделей рядом;
- цитирование и выбор сообщения для передачи следующей модели;
- локальные шаблоны prompt;
- история изменений спецификации;
- undo безопасных UI-действий;
- реализация command palette по `COMMAND_PALETTE_AND_APP_COMMANDS_RU.md`.

## Отложено намеренно

- виртуализация списка проектов — только после измеренной проблемы производительности;
- generic provider URL — запрещён без adapter, allowlisted origins, capability manifest, browser profile, auth detector, selector/state tests и security policy;
- autonomous code runtime и изменения CLI/execution protocol — отдельная фаза и отдельное разрешение.
