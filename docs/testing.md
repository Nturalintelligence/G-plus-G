# Проверки по уровням

Этот документ не требует полного набора тестов после каждой маленькой правки.

## Микрошаг

- одна проверка непосредственно затронутого контракта;
- просмотр diff;
- ручной статус остаётся `UNVERIFIED_MANUAL`, пока владелец не проверил функцию.

## Согласованный checkpoint или PR

- связанные focused tests;
- необходимый typecheck/build для изменённой подсистемы;
- полный `npm run check` выполняется в CI либо локально по отдельному решению.

## Release candidate

Полный профиль находится в `docs/UAT_RUNBOOK.md` и
`docs/RELEASE_CHECKLIST.md`. Только на этом уровне выполняются package,
packaged smoke, install/upgrade/rollback, provider matrix и soak.

CAPTCHA или challenge всегда останавливают автоматизацию. Live provider tests,
длинные диалоги, backup/restore и массовые запросы нельзя запускать как обычную
локальную проверку: требуется отдельная команда владельца.
