# Phase E — безопасное массовое управление проектами

Дата проверки: 2026-08-26.

## Аудит и исправление

Базовый UI выбора и корзины уже присутствовал, но окончательное batch-удаление вызывало отдельную транзакцию для каждого проекта. Ошибка в середине могла оставить частично удалённый набор. Кроме того, подтверждение показывало число ссылок на файлы, а не число уникальных локальных путей.

- Добавлено атомарное `ProjectRepository.deleteProjects`: сначала проверяется весь набор, затем он удаляется одной транзакцией.
- IPC сначала подтверждает, что каждый проект находится в корзине, и только затем запускает атомарное удаление.
- Счётчик файлов использует объединение уникальных `local_relative_path` attachments и downloaded artifacts.
- Физические файлы не удаляются напрямую: reference-safe orphan cleanup сохраняет shared/deduplicated artifacts и применяет установленный grace period.
- Provider adapters, внешние веб-чаты и Phase D не изменялись.

## Проверки

- Unit: восстановление transcript, дедупликация batch, уникальные файловые пути, успешное атомарное удаление и rollback при отсутствующем ID.
- Electron production smoke на временном профиле: 32 проекта, явный выбор трёх, корзина после перезапуска, восстановление двух, отмена и подтверждение окончательного удаления, сохранность transcript.
- 1920×1080 dark, 1366×768 light, 1100×700 dark; browser zoom `1` (100%).
- На 1100×700 `scrollWidth === clientWidth`.
