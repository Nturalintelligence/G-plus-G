# Phase E — аудит UI

Статус Phase D: `IMPLEMENTED_LOCALLY / LIVE_UAT_BLOCKED_EXTERNAL`. Provider runtime в UI-этапах не изменяется, дополнительный Live UAT запрещён.

## Root causes

- **Спецификация:** layout создавал третью grid-колонку, но production CSS для `.inspector`, карточек разделов и timeline отсутствовал. Контент увеличивал высоту панели; отдельного scroll-container и закреплённых действий не было.
- **Активный проект:** состояние `selected` назначалось внешнему прямоугольному `.project-row`, тогда как скругление принадлежит вложенной `.project-btn`.
- **Иконки:** категории спецификации собирались строками emoji и зависели от системного шрифта.
- **События:** весь массив выводился как raw `eventType + ISO timestamp`, без фильтра, локализации, раскрытия и ограничения количества.
- **Сообщения:** единые padding/max-width и отсутствие action bar делали короткие сообщения крупными и не давали доступного копирования.
- **Модели:** sidebar row открывал общие настройки вместо provider-specific управления.
- **Проекты:** отсутствовали явный batch selection и модель локальной корзины.
