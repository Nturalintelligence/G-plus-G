# Security policy

Пожалуйста, не публикуйте сведения об уязвимостях, cookies, токены, browser-профили или пользовательские базы данных в Issues.

Сообщите об уязвимости владельцу репозитория через приватный канал GitHub Security Advisories: **Security → Advisories → Report a vulnerability**.

В отчёте укажите версию G+G, операционную систему, ожидаемое и фактическое поведение, а также минимальные шаги воспроизведения. Перед отправкой удалите личные данные и содержимое аккаунтов провайдеров.

Поддерживается последняя опубликованная версия. Экспериментальные ветки не считаются стабильными и могут содержать незавершённые функции.
